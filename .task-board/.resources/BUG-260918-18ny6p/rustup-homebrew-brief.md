# Brief — BUG-260918-18ny6p: install-rust-toolchain.sh must also find a Homebrew rustup (rose-air lane)

Facts: main run 35302875022 (03:41Z) was GREEN on rose-air — job shell /opt/homebrew/bin/bash, rustup = Homebrew build ("self-update is disabled for this build of rustup"). Main runs 35306933411 (04:55Z, with the BUG-260918-3u6qqq script) and later fail with `rust-pin: rustup is not installed on this runner`: the job shell is /bin/bash, so the runner service started with a minimal launchd PATH (no /opt/homebrew/bin), and ~/.cargo/bin contains only the toolchain proxies (rustc, cargo, ...) — the Homebrew formula keeps the rustup binary at /opt/homebrew/bin/rustup, so the CARGO_HOME/bin lookup does not find it. Fix the script, not the runner.

Required change (small, exact; keep everything else as landed by PR #77):
1. In .github/ci/install-rust-toolchain.sh, after computing cargo_home and prepending "$cargo_home/bin", resolve rustup by probing in order: `command -v rustup`; "$cargo_home/bin/rustup"; "${HOMEBREW_PREFIX:+$HOMEBREW_PREFIX/bin/rustup}"; /opt/homebrew/bin/rustup; /usr/local/bin/rustup. Use the first executable found: prepend its directory to PATH and append it to GITHUB_PATH (keep "$cargo_home/bin" on PATH/GITHUB_PATH too, the proxies live there). If none is found, fail closed with the existing docs-named message. Invoke rustup by the resolved path or via PATH — either way the post-install `rustc`/`cargo` checks stay.
2. gate-selftest.sh (install-rust-toolchain section): add the row "rustup only under a fake Homebrew prefix (HOMEBREW_PREFIX=$WORK/fake-brew, PATH without it, CARGO_HOME/bin without rustup) → succeeds and records the fake install invocation"; keep the CARGO_HOME-only and absent-everywhere rows green/named. Reuse the fake-rustup harness; no network.
3. docs/self-hosted-runner-setup.md: state that the runner service PATH (launchd) does not include /opt/homebrew/bin, that a Homebrew rustup is found by the lane itself, and mention as an alternative that the runner's `.path` file can carry /opt/homebrew/bin. Do not ask the operator to reinstall anything.
Out of scope: rust-toolchain.toml, rust-pin-guard.sh, ci.yml, internal/rustsource.
