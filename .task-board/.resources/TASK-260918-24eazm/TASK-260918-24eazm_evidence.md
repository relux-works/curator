## Key decisions

- **chezmoi on Windows is `%USERPROFILE%\.local\share\chezmoi`, not
  `%LOCALAPPDATA%`.** Verified from chezmoi's own source (citations 1–2):
  `defaultSourceDir` resolves through `go-xdg` with no platform switch, and
  `go-xdg` builds the default from `os.UserHomeDir()` (`%USERPROFILE%` on
  Windows). Community reports of `%LOCALAPPDATA%\chezmoi` describe explicit
  `sourceDir` settings, not the default. This answers the TASK-260906-vlrjo1
  open question against the implementer's hypothesis; `%LOCALAPPDATA%` /
  `%APPDATA%` are still defined in the resolution rules for future rows.
- **Presence is `lstat`-directory.** Matching §4/§8.4 link discipline, the
  resolved path itself must be a directory; a symlink (even to a directory),
  a regular file, an unreadable path, or a failed inspection is quiet — and
  per §8.4 never reported as absent. Note: the current manager code uses
  `os.Stat` (follows links); the follow-up implementation task aligns it to
  `Lstat` for this check.
- **XDG variables only; manager-private relocations are out.** The heuristic
  honors `$XDG_DATA_HOME` / `$XDG_CONFIG_HOME` where the cell names them.
  The unset/empty/relative → default fallback is the heuristic's own
  resolution rule (per the XDG specification); upstream managers differ
  (citations 2a/3a vs 5a) and `verified` makes no claim about their
  fallback behaviour. Chezmoi `sourceDir`, `$YADM_DIR` / `$YADM_DATA`,
  `$HOME_MANAGER_CONFIG`, system `$XDG_DATA_DIRS` entries, and sibling
  paths (chezmoi config dir, yadm `YADM_DIR`, HM generation links) are
  explicitly not heuristic inputs — a stated bound, structurally pinned
  (closed `env` key set; a `YADM_DATA` case is refused by the gate).
- **`none` means inert.** stow/dotbot keep no state directory of their own
  (per the brief, none invented); home-manager and yadm have no fixed native
  Windows location (Nix-only; bash script whose POSIX layers bring their own
  `$HOME`). Inertness is pinned: a `none` cell must carry a null state and
  is never named.
- **First-present in table order wins** when several managers are present
  (pinned by two multi-present cases).
- **Rollout is direct with changed detection semantics** (R3): default path
  spellings unchanged; XDG relocation honoured and symlinked directories
  no longer count. No manager change in this leaf.
