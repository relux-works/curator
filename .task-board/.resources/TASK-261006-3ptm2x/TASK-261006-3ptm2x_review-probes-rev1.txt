# Reviewer probes for revision 1

These synthetic tests ran only in a disposable clone under internal/audit.
No code in the Story workspace was changed.

The temporary hashing instrumentation adds a zeroed exported counter
ReviewObservedNULV1Hashes, incremented immediately before digest.Write(content)
in ContentSHA256 when strings.ContainsRune(string(content), 0). It observes
existing behavior without changing hashing or admission.

The cache fixture with equal digest text and a legacy carrier tests the §8
version-pair requirement; it does not claim an actual cross-version SHA-256
collision. Marker collision fixtures are actual equal-v1-digest trees.

The final seven-probe run had two passes and five failures. Earlier prototypes
with a missing SKILL.md or excluded docs root were discarded; final frozen
context fixture contains SKILL.md and an included assets/a.bin. Two initial
mutants that failed to compile were discarded and rerun as valid mutations.

## Bounded test runner

```python
import sys,subprocess,time,json,re
from pathlib import Path
root=Path(__file__).parent
clone=root/'candidate'
label,pkg,regex=sys.argv[1:]
def health():
 p=subprocess.run(['launchctl','print','system/com.apple.security.syspolicy'],capture_output=True,text=True)
 out=p.stdout
 count=re.search(r'successive crashes = (\d+)',out)
 return {'running':'state = running' in out,'successive_crashes':int(count.group(1)) if count else None}
before=health()
if not before['running']: raise SystemExit('syspolicyd not running; defer build')
start=time.monotonic()
cmd=[str(Path.home()/'.local/bin/mini-build-lock'),'run','opaque','--','env','GOFLAGS=-work','go','test','./internal/'+pkg,'-run',regex,'-count=1','-timeout=6m']
if label=='attacks': cmd.append('-v')
p=subprocess.run(cmd,cwd=clone,capture_output=True,text=True)
after=health()
output=re.sub(r'WORK=.*','WORK=<retained>',p.stdout+p.stderr)
record={'case':label,'package':pkg,'regex':regex,'exit':p.returncode,'duration_seconds':round(time.monotonic()-start,3),'before':before,'after':after,'output':output}
with (root/'review-checks.jsonl').open('a') as f: f.write(json.dumps(record)+'\n')
```
