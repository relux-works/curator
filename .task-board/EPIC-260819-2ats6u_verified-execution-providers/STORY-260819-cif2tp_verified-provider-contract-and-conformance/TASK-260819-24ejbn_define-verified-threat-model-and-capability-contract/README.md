# TASK-260819-24ejbn: define-verified-threat-model-and-capability-contract

## Description
Research and normatively map attacker powers, trust boundaries, required guarantees, and provider capabilities across the three host platforms.

## Scope
Define workload and administrator threat assumptions; process, file, environment, network, resource, time-of-check and time-of-use, crash, reboot, upgrade, rollback, and compromised-client cases. Separate mandatory guarantees from optional capabilities and define evidence needed to claim each.

## Acceptance Criteria
A reviewed platform-neutral threat model and closed capability registry maps every verified claim to enforceable and observable evidence, declares unsupported cases fail closed, and identifies no guarantee based only on Curator client self-attestation.
