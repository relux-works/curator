# Stage build plans before installation mutation

## Description
Refactor project and global installation into an explicit read-only plan followed by private build staging. All validation and trust gates must finish before toolchain or source-aware compilation, and every build must finish before shared installation mutation.

## Scope
Own immutable plan types and private build-staging orchestration within internal/install, with narrow injected interfaces for toolchain, cache inspection, builder, clock, and filesystem generation reads. Keep live target mutation adapters outside this task and owned by TASK-260720-2284br. Preserve closure provider order and sort build command names lexically within a node. Plan source identity and context, collision, system and MCP requirements, audit, registry attestation, and moved-tag gates before building. Inspect protected cache state and emit per-command hit, would-preflight-and-build, would-rebuild-untrusted-cache, corrupt, or unsupported results. Dry-run may create and remove exactly one manager-owned operation-private ephemeral root containing only closure-workspace and toolchain-probe subtrees, never invokes go list or go build, never writes persistent state, and removes the root on every return. A real run builds every miss in operation-private staging and returns a staged result but does not publish or change live installation targets.

## Acceptance Criteria
A failing manifest, skill check, closure, collision, system, MCP, audit, registry, moved-tag, toolchain, cache, go-list, or go-build step occurs before any persistent install, consumer, marker, runtime, shim, adapter, journal, or live-cache mutation; build misses execute provider-first and command-lexical and successful staged outputs remain private; failure of build two after build one succeeds deletes staging and preserves prior installation and live cache byte-for-byte; cache hits perform no source-aware Go command; dry-run reports exact logical source, target, key, and outcome, performs no go list or build, creates at most one manager-owned operation-private ephemeral root under the caller temporary directory containing closure-workspace and toolchain-probe state only, removes that root on every return, and leaves every enumerated persistent path and lock absent or unchanged; project and global legacy script-only install tests remain green.
