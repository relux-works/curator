# STORY-260810-rn6fg1: discover-skill-cli-language-inventory

## Description
Inventory the actual skill-facing CLI estate and collect evidence before expanding adapter language coverage.

## Scope
Confirm Swift, Kotlin, and C as baseline; inspect real skills, manifests, build metadata, launchers, packaging, and runtime requirements; evaluate Rust, Python, Node/TypeScript, Dart, and .NET without pre-committing them.

## Acceptance Criteria
An evidence matrix identifies existing skill/CLI implementations and language demand, recommends any additions beyond Swift, Kotlin, and C, and maps build/install, executable resolution, invocation/version probing, packaging/runtime expectations, and conformance-test requirements.
