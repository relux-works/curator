# EPIC-260810-271m92: skill-facing-cli-adapters

## Description
Define a cross-language adapter direction for skill-facing CLIs without starting implementation.

## Scope
Baseline adapters: Swift, Kotlin, and C. Evaluate additional languages only after evidence-based discovery of the real skill and CLI inventory.

## Acceptance Criteria
Direction covers build/install, executable resolution, invocation and version probing, packaging and runtime expectations, and conformance tests; Rust, Python, Node/TypeScript, Dart, and .NET remain evaluation candidates rather than commitments.
