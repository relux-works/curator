# Portable skill-facing CLI adapters

## Description
Implement conservative portable skill-facing CLI adapters backed by complete recursive source closure and explicit portable assurance receipts. Portable is the default CLI-only mode and does not claim lossless OS observation.

## Scope
Current delivery cycle: common portable assurance contract; curator-spec release; Rust; Node/TypeScript; Swift and SwiftPM-supported C, C++, Objective-C, and Objective-C++. Go remains the baseline and Python remains reference input. Kotlin, Dart, and .NET are deferred. Vendored compiled executable artifacts remain globally prohibited. Verified host providers are architecturally anticipated but delivered only by the separate verified epic.

## Acceptance Criteria
A released normative contract distinguishes portable from verified without silent downgrade or claim inflation. Portable executions emit typed capability evidence and output-verification receipts, recursively capture auditable source closure, rebuild offline from immutable inputs, bind dependency and toolchain checkpoints, support mixed-language graphs, reject unsupported cases and all vendored compiled artifacts, and pass independently reviewed language-specific and cross-language conformance.
