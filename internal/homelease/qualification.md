# Home lease qualification map

This map indexes the 68 semantic pairs, in order, in the [accepted corpus](https://github.com/relux-works/curator-spec/blob/3f8ffb7f15213872c66ceec28501b9e51d56ac5c/conformance/home-leases-v1/cases.json). It is **not a claim of 68 complete runtime pairs**. Each row names actual tests and the remaining limit. `store`/`guard` identify the local boundary tested; store lifecycle positives use explicitly synthetic independent authority/observation. They do not qualify the public observer. `partial` and `consumer gap` remain acceptance gaps. No skipped consumer test or made-up launcher is counted as a pass.

Tests are in this package, `state/`, `observation/`, `../envprofile/homelease*_test.go`, and `../../cmd/curator/env_homelease_test.go`. Refusal preimages are checked before positive controls. The producer observation vectors are an additional transport oracle, not a substitute for semantic pairs.

## Production observer boundary

The CLI wires `SessionManagerObserver` to `curator-run session-manager observe <manager-id> --session <SES-handle> --json`. Help, FRONT-DOOR and exact closed schemas were verified at launcher main `870e62350a008f8b71d368a054140221cbc97925`. The two schemas and producer vector file are copied byte-for-byte under `observation/`, resolving references offline. Transport is capped at 64 KiB, requires strict JSON with closed fields, discards stderr and has a 25-second total deadline (producer describe/status each allow 10 seconds).

The adapter checks registry incarnation, handle, manager and generation. It never copies caller process/request/Werkstatt fields or labels into trusted evidence. Current v1 lacks OS process incarnation, independently bound request/Werkstatt, no-start operation observation, complete descendant termination and ownership reconciliation. Even exact `down` must refuse. Prepared holders cannot call a command requiring a session. Missing executable, malformed/oversized output, nonzero exit or unknown evidence also retains protection. The production adapter is connected for authoritative reads, **not qualified to admit bind or release**. An accepted producer proof contract is required; adding invented members to a closed schema or weakening HL09 is not an implementation option.

`TestProductionObserverRetainsUnprovenLease` exercises the real bounded process transport with synthetic executables and the real store. `TestProductionObserverBindAndPreparedRelease` checks non-admitting production bind/prepared-release paths against independently supplied lifecycle positives. `observation.TestPublishedObservationVectors` and `TestObservationTransportAndClosedProofs` cover the exact closed wire contract.

## Writer and consumer audit

All 18 writer rows have code admission hooks, either at their held operation or common transaction publisher/recovery. Rows 25–42 above distinguish that code audit from complete variant qualification. The central gates are `homeLeaseGuard`, `homeLeaseGuardPlan`, `homeLeaseGuardUndo`, `state.GuardMutation` and the transaction engine's complete target inventory. They check forward and rollback before replay, retaining the continuous real managerlock witness. Broad legacy whole-manager paths currently refuse conservatively; they are not qualified as fully disjoint writers.

New hooks in this continuation: the one-line production observer argument in `cmd/curator/env.go`; `native_mcp.go` runs the existing ownership preflight before operation admission, then revalidates captured inputs under the held operation rather than replanning against its own postimage. The latter was exposed by the W11 positive control. The race fixture sends native paths in its existing closed stdin payload and does not inherit per-test provider overrides across the helper boundary. No containment commit is rewritten.

GC's runtime and protected build-cache sweeps pass through the shared lock. Fixture publications exercise the existing cache APIs, prepared/unknown home roots, durable project roots, explicit home break and full pending-acquire refusal; the artifact bytes, inputs, portable receipts and independent authority are synthetic. Reconciliation alone does not discard durable project composition roots. The production profile materializer currently supplies empty build/runtime reference lists. Production profile compiled-closure activation and qualification remain separate work described in `docs/design/profile-skill-runtime.md`; these fixture roots do not qualify that bridge.

HL21–HL24 remain consumer requirements. Launcher main inspected here has no `lease_requested` integration. Curator cannot qualify durable op.json ordering, zero/exactly-one manager calls, immediate bind, abandon/bypass handling or lane/Werkstatt admission by simulating them inside its store tests. No live manager/provider qualification or activation was performed.
