# TASK-260728-ypbuav: maintain-official-toolchain-install-guidance

## Description
Publish and test the manager-owned official installation and verification guidance catalog for supported toolchains and platforms.

## Scope
Official primary-source URLs and recommended package/toolchain managers for macOS, Windows and Linux; architecture and shell differences; verification commands; catalog versioning, localization boundary, stale-link checks and security warning that managers never auto-execute instructions.

## Acceptance Criteria
Every supported toolchain/platform diagnostic resolves to reviewed current guidance backed by primary sources, snapshot tests are stable, stale or unavailable guidance degrades honestly without weakening the install failure, and no skill or repository can override catalog content.
