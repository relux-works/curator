# STORY-260728-10wxx2: protocol-schema-v7-external-build-repositories

## Description
Extend curator-spec with the accepted schema-7/rc.5 contract for source-audited external Git repositories and incorporate the authorized portable manager-owned go-v1 host-execution policy. Preserve closed package-influence boundaries while separating portable delivery from the future hardened sandbox profile.

## Scope
curator-spec normative prose, JSON schemas, generated cases, conformance vectors, manager profile and CLI contract, portable execution-policy identity, authoring documentation and rc.5 candidate release evidence. No Curator or cocoaskills implementation and no hardened host adapter implementation.

## Acceptance Criteria
Schema 7 and every new wire artifact are closed, versioned and implementation-ready; external source is resolved, raw-snapshot validated, hashed and independently audited before cache or compiler work; inaccessible sources follow typed offline-warning versus install/audit hard-failure semantics; package-controlled argv, environment, output paths, executable names, credentials, hooks, signing and generic language drivers remain forbidden. Schemas 1-5 remain byte compatible and schema-6/7 declaration shapes stay closed. go-v1 normatively identifies a portable manager-worker-v1 execution policy with honest capability evidence and no hardened claim; portable versus future hardened cache, receipt, marker and claim identities cannot alias. Generated cases, validators, compatibility guards, deterministic regeneration and rc.5 release gates pass.
